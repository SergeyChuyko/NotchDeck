# Исходник документации

`NotchDeck.pdf` собран не руками, а программой — чтобы его можно было пересобрать,
когда приложение изменится, и чтобы снимки разделов не устаревали молча.

Пересборка:

```sh
SRC=../../NotchDeck/Notch
swiftc -o doc main.swift parts.swift mock.swift \
  $SRC/NotchShape.swift $SRC/NotchConfig.swift $SRC/NotchSection.swift $SRC/NotchSystemControls.swift
./doc
```

Что важно знать про эти файлы:

- `mock.swift` — разделы с **образцовым** содержимым. Настоящие данные брать нельзя:
  документ уходит другим людям, а в скриншотах и буфере лежит личное. Размеры и вёрстка
  повторяют приложение, а числа геометрии берутся прямо из `NotchConfig` и `NotchShape`.
- Текст документа набран Helvetica Neue, а не системным шрифтом. Дело не во вкусе:
  вариативный SF при печати в PDF отдаёт кириллическую «к» как «ĸ», и поиск по документу
  ломается. Мокапы при этом остаются на системном — там важно сходство со скриншотами.
